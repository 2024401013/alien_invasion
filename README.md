# Alien Invasion

基于《Python编程：从入门到实践》第12-14章的2D射击游戏。完成全部基础功能，并扩展实现最高分持久化、外星人主动射击、盾牌道具与程序化音效。

## 🎮 功能亮点

### 基础功能
- 飞船左右移动与空格键发射子弹
- 外星人舰队自动横向移动并触边转向
- 子弹与外星人碰撞检测
- 生命值系统（初始3条命）
- 动态难度提升（每关加速）

### 扩展功能
- **最高分持久化**：使用 JSON 保存历史最高分，重启不丢失
- **外星人主动射击**：随机向下发射红色子弹，形成双向交火
- **盾牌道具系统**：击败外星人后低概率掉落蓝色护盾，拾取后激活3秒无敌状态
- **程序化音效**：使用 numpy 动态生成射击、爆炸、道具等5种音效，无需任何音频文件

## 🛠 技术栈

- Python 3.8.20
- Pygame 2.6.1
- NumPy

## 🚀 快速开始

### 安装依赖
```bash
pip install pygame numpy
```

### 运行游戏
```bash
cd alien_invasion
python src/main.py
```


## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| ← → | 控制飞船移动 |
| 空格键 | 发射子弹 |
| S键 | 消耗1000分获得盾牌（如分数足够） |
| Q键 | 退出游戏 |
| 鼠标点击 | 游戏结束后点击"Play"按钮重新开始 |

## 🔧 扩展功能详解

### 盾牌防御机制
- 盾牌激活期间飞船无敌（视觉上会闪烁）
- 根据练习14.7要求，仅抵挡正面攻击，侧面攻击仍可造成伤害

### 程序化音效
- 所有音效均通过代码生成，无需外部音频文件
- 包含：射击声、爆炸声、盾牌音效、道具获取音效、游戏结束音效
